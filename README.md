# SOC Portfolio — Аналитик безопасности

Привет! Я студентка 3 курса по специальности «Информационная безопасность».  
Этот репозиторий — моя практика в направлении SOC: расследование инцидентов,
анализ логов, работа с SIEM, маппинг атак на MITRE ATT&CK.

## Платформы, где я тренируюсь

- [TryHackMe](https://tryhackme.com) — путь SOC Level 1
- [LetsDefend](https://letsdefend.io) — симулятор работы аналитика SOC

## Стек технологий

- SIEM (Elastic Stack, Wazuh)
- Wireshark — анализ сетевого трафика
- Sysmon / Windows Event Logs — анализ логов ОС
- MITRE ATT&CK — маппинг техник атак
- SIGMA — создание правил детектирования

## Структура репозитория

```
soc-portfolio/
  README.md                  # эта страница
  writeups/                  # отчёты по расследованию инцидентов
    tryhackme-01-xxx.md      # отчёт по комнате с TryHackMe
    letsdefend-01-xxx.md     # отчёт по алерту с LetsDefend
  detection-rules/           # правила детектирования (SIGMA, Suricata)
  assets/                    # скриншоты и схемы
```
